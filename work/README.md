# work/

아직 실행/검증 전이지만 **공개를 전제로** 미리 정리해두는 초안 공간.

- `internal/`: 완전 비공개(gitignore) — 로드맵, 체크리스트, IP 등 운영 원본
- `work/`: 공개 저장소에 커밋됨 — 아직 진행 중인 스테이지의 설계/의사결정을 lessons/ 톤으로 미리 써두는 곳
- `lessons/`: 실제 실행·검증까지 끝난 스테이지의 최종 정리본

작업이 끝나고 검증되면 `work/`의 내용을 다듬어 `lessons/`로 옮기고 대응하는 `scripts/`를 채운다. 진행 중에는 이 문서가 최신 설계를 반영하도록 갱신한다.
